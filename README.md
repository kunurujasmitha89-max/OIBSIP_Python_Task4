# OIBSIP Python Task 4 – Weather Dashboard

## Objective

Develop a Python-based Weather Dashboard that displays real-time weather information for a selected city.

## Technologies Used

* Python
* Tkinter
* Requests
* Pillow
* OpenWeather API

## Features

* Search weather by city
* Temperature and weather condition
* Humidity, wind speed and pressure
* Visibility
* Sunrise and sunset
* Minimum and maximum temperature
* Date and time display
* User-friendly graphical interface

## Process

1. Designed the GUI using Tkinter.
2. Integrated the OpenWeather API.
3. Retrieved and processed weather data.
4. Displayed the information in the dashboard.
5. Tested the application with different cities.

## How to Run

```bash
pip install -r requirements.txt
python weather.py
```

Add your OpenWeather API key before running the application.

Successfully developed a functional Python Weather Dashboard that retrieves and displays real-time weather information.
